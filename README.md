# Bangumi 个性推荐

面向 `wylt` 个人主页的动画回顾与推荐组件。推荐只读公开的 Bangumi 收藏与评分；独立的“活跃度热力图”组件保持原有观看集数口径，不随推荐算法更新。

独立的“我的放送表”组件在首页和 `/calendar` 展示当前登录用户收藏与每周放送表的交集，按日期分列、条目纵向排列。

## 0.11.0：从零重建动画推荐

- 废弃旧版的“7 分中性/8 分喜欢”硬口径、固定 80/20 权重、前 1000 排行与 12 个标签候选上限，以及日系、篇幅、OVA/剧场版等资格过滤。旧文件仅为历史实验留存，不进入发布脚本。
- 以个人实际评分相对站内评分的差异为学习目标，采用正则化内容特征模型；从约 100 位公开用户中按共同评分的去偏相关性选出最多 40 位正向近邻，由其评分作品发现候选。只有按系列分组的五折检验显示额外增益时，协同评分特征才参与最终排序。
- 月度任务按限速抓取约 100 位有足够公开动画评分的用户，再补充 Bangumi 公开排行条目的站点评分；只发布聚合后的前 500 个候选及解释，不发布他人的原始评分矩阵。月度数据由 [自动工作流](.github/workflows/monthly-recommendations.yml) 更新，不需要每月修改组件版本。
- 页面重新核对 `wylt` 所有状态的动画收藏，想看、在看、看过、搁置、抛弃均排除。结果展示样本日期、参与人数、模型类型与预测分；支持分页、暂时隐藏和撤销。站外推荐清单不可用时使用随当前版本打包的前 50 条快照，避免在所有 Bangumi 页面加载完整清单。
- 推荐暂只覆盖动画：当前动画有足够评分样本，书籍、音乐、游戏和三次元样本不足以对其输出同等可信的个性化排序。动画回顾仍保留。

模型的离线评测、候选覆盖、资源成本与已知限制见 [重建实验报告](experiments/2026-09-27-rebuild/REPORT.md)。五折指标是历史评分上的代理评测，不能证明用户将来一定喜欢，也不等同于线上点击或完成率。

## 工作方式

1. 月度任务读取 `wylt` 的公开动画收藏、[固定公开用户样本](data/peer-cohort.json)与 Bangumi 动画排行元数据；请求间隔默认至少 1.5 秒，429/服务器错误会退避。逐用户采集结果写入忽略目录，24 小时内的中断可续跑；GitHub 月度任务在全新环境中仍全量读取。
2. 按作品系列划分训练/验证折，比较站内评分校准基线、内容模型、内容+协同模型。对标签和年份拟合 L2 正则化残差模型；协同特征不稳定时自动退回内容排序，但候选仍由正向近邻的共同评分行为发现。
3. 只把带标题、封面、标签、站点评分、预测分和简短解释的清单写入 `public/recommendations.json`。清单不包含样本用户名或逐人评分。候选不设国家、形式和最少集数门槛。
4. 浏览器访问个人主页时，组件优先读取已保存的公开收藏并过滤所有已标记条目，缓存不定时过期；“更新”会强制核对最新收藏。推荐清单超过六小时才单独在后台检查更新；已有片架无需等待网络。页面显示实际收藏核对时间，保留五列/窄屏自适应布局；不运行大矩阵训练，也不修改任何收藏。

月度自动更新依赖 GitHub Actions 与 Bangumi 公开接口；若更新失败，旧清单保留，页面会显示实际数据日期。新评分会在下一次月度训练进入排序；页面上的“更新”只同步当前收藏与最新清单，不能即时重训模型。

## 构建与验证

在仓库根目录执行 `npm run verify`，会重建三个组件、检查语法，并分别运行当前测试和历史兼容测试。`npm test` 只验证当前实现，`npm run test:legacy` 单独验证归档源码。浏览器预览从 `demo/index.html` 导航至 `demo/profile.html` 等页面；验收应覆盖桌面/窄屏、暗色、分页、展开理由、隐藏/撤销和网络回退。发布产物为 `dist/bangumi-personal-recommender.user.js`；同目录 `.bgm.txt` 与它逐字相同，可粘贴到 Bangumi。热力图产物为 `dist/bangumi-personal-timeline.user.js`。浏览器验收条件详见开发维护说明，`npm run verify` 不自动启动浏览器。

首次生成或月度刷新聚合数据：`node scripts/refresh-recommendations.cjs`。需要 Node.js 22、Python 3.12 与 NumPy 2.x，且会持续读取大量公开 API 页面；不要在普通页面加载时运行。测试原始数据放在 `scripts/.cache/`，已被 Git 忽略。

## 我的放送表 1.0.0

- 在首页原“每日放送”位置与完整放送页展示个人收藏；大封面、中文名称、收藏状态，按日期分列、番剧纵向排列；桌面最多三列/宽版四列，窄屏单列，支持暗色、键盘日期选择和原始界面切换。
- 默认保留想看、在看、看过、搁置、抛弃全部状态，提供“仅在看”筛选。只按条目 ID 取交集，不按标题、评分、国家或形式筛选。
- 默认读取公开收藏，可点击“包含私密收藏”通过本站登录态完整同步五种收藏状态；同步可取消，完整分页验证成功后才更新本地收藏缓存。收藏列表不保存评分、标签、评论或登录凭据。
- 网络失败保留旧数据并说明错误；首次失败保留原始放送表。未登录及 `?personal=off` 不加载个人数据。
- 日期代表 Bangumi 的每周放送安排，不保证停播、延期或实际更新集数；不推算具体时间。数据来源、缓存和维护说明见 [放送组件说明](docs/calendar.md)。
