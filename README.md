# Bangumi 个性推荐

面向 `wylt` 个人主页的动画与书籍推荐组件：推荐评分由全站评分折算与全站用户标签的均分（来自我的公开评分）在浏览器本地计算，从高到低排序，仅手动更新。独立的“活跃度热力图”组件保持原有观看集数口径，不随推荐算法更新。

独立的“我的放送表”组件在首页和 `/calendar` 展示当前登录用户收藏与每周放送表的交集，按日期分列、条目纵向排列。

## 1.0.1：推荐评分加入探索因子（全站 3 : 标签 7）

- 推荐评分从两项等平均改为加权：**全站评分权重 3、标签评分权重 7**（即 `final = 全站分×0.3 + 标签分×0.7`，仍保留 2 位小数）——标签分充当探索因子，避免全站口碑主导排序；没有已知标签的作品仍只用全站分。
- 卡片上的两项小字展示不变；排序随之变化（标签契合度高的作品上升）。

## 1.0.0：彻底重写——标签均分制推荐，动画与书籍两个模块

- 协同过滤管线整体退役：不再有月度采集、公开用户样本、预测模型、聚合清单与六小时后台检查；推荐评分完全在浏览器本地计算，组件不发布任何聚合数据。
- 评分规则：从我评过分的条目（打分即可，不限收藏状态）身上的**全站用户标注标签**建立标签分数库——我的 10 分制评分就是标签在该作品下的得分，标签分数取均分；候选作品的标签分 = 其所有标签的标签分数均分 ÷ 2，全站分 = 全站评分 ÷ 2，**推荐评分 = 两项平均（保留 2 位小数）**，从高到低推荐。
- 候选池扩大到全站排行中评分人数 ≥ 500 的全部条目；排除我已打分的作品（仅收藏未评分照常参与）、OVA、以及关联条目中存在我已评分作品且关系为「不同演绎」的条目（关联结果缓存 30 天）。动画列 30 部、书籍列 20 部，两模块共用同一套评分标准、分开列出、各自带更新按钮。
- 展示只保留：封面与名字（链到条目页）、推荐评分、一行小字的全站评分与标签评分；分页每页 5 部。没有理由、隐藏撤销、模型说明等冗余内容。
- 刷新只接受手动：挂载零网络请求，只渲染本地缓存；「更新」依次核对收藏（含标签）、读取排行候选、逐个复核关联资格，全程限速，失败保留上次结果。

## 工作方式

1. 页面挂载时只读本地缓存渲染，零网络请求；推荐结果的更新只由模块右上角的「更新」按钮触发。
2. 手动更新按限速顺序执行：核对我在 Bangumi 的公开收藏（动画/书籍分开，含每部作品的全站用户标签）→ 以我评分过的条目构建标签分数库 → 分页读取全站排行候选（评分人数 ≥ 500）→ 按标签均分与全站评分折算打分排序 → 从高到低逐个复核「不同演绎」关联，取满动画 30 部 / 书籍 20 部。
3. 候选的关联结果缓存 30 天；分数计算全部在浏览器本地完成，不请求第三方服务，不发布任何聚合清单，也不调用月度任务。
4. 任何一步失败都保留上次结果并提示；组件不修改收藏、评分或标签。

月度协同过滤管线（公开用户样本、预测模型、`public/recommendations.json` 聚合清单）已在 1.0.0 整体退役，历史实现见 [旧版说明与版本历史](docs/legacy-readme-through-0.10.8.md) 与仓库历史。

## 构建与验证

在仓库根目录执行 `npm run verify`，会重建四个组件、检查语法，并分别运行当前测试和历史兼容测试。`npm test` 只验证当前实现，`npm run test:legacy` 单独验证归档源码。浏览器预览从 `demo/index.html` 导航至 `demo/profile.html` 等页面；推荐验收应覆盖桌面/窄屏、暗色、两个模块的分页、卡片内容最小化、缓存优先与手动更新失败保留。个性推荐产物为 `dist/bangumi-personal-recommender.user.js`，动画回顾产物为 `dist/bangumi-personal-stats.user.js`；两者同目录 `.bgm.txt` 与其逐字相同，可粘贴到 Bangumi。热力图产物为 `dist/bangumi-personal-timeline.user.js`。

## 1.0.25：每日活跃重画为「账本柱」——线性封顶轴、峰值标注、动量进标题

- 柱子改为按日历聚合：近一年按周一锚定的自然周（“每周 N 集”就是真实的一周），两年以上或窄屏退到自然月；线性轴下柱高与集数严格成正比，周与周可以直接比较。轴顶取阶梯上不小于 p90 的档（本账号周数据为 80），超过的爆发周封顶画到顶并加深色切角帽——真实分布里只有 3/53 的周被截断，读数条里始终有完整数字；截断是显式标注的，比对数轴悄悄压缩所有柱子诚实。
- 峰值桶改用色阶最深的一档并在柱顶标注真值，作为整张图的视觉入口；网格减到 3–4 条等距发丝线；横轴标签落在日历边界（周桶在月份变化处标周一日期，月桶标年份）。
- 均线移除：势头改由标题行文字表达——「近4周 均28 集/周 ↓69%」。动量只统计完整的周/月（进行中的当前桶不参与），完整桶不足 8 个时不显示；读数条去掉均线段，悬停进行中的桶会标注（本周/本月）。

- 实测（真实 365 天分布，820px）：51 根周柱、中位柱占绘图区 42.5%、峰值 128 封顶在轴顶、刻度 20/40/60/80 等距；动量 ↓69% 与 7–8 月补番高峰后的回落一致。截图 `artifacts/trend-real-820.png`、`trend-real-dark-820.png`、`trend-real-375.png`。
