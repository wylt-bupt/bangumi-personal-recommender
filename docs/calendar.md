# 我的放送表

开发遵循根目录 [AGENTS.md](../AGENTS.md)。组件独立于推荐/回顾与活跃度热力图，当前版本取自 `package.json.calendarVersion`。

## 数据与显示口径

只显示当前登录用户动画收藏与 Bangumi 每周放送表的 ID 交集。五种收藏状态始终一起参与匹配，不提供状态过滤；没有评分、国家、篇幅或作品形式条件，不进行系列归并或同名匹配。中文名缺失时用原名。标题用 DOM `textContent` 写入，封面仅接受 `lain.bgm.tv` 的 HTTP/HTTPS 地址并规范为 HTTPS；图片失败显示“暂无封面”。

首页默认读取 `https://api.bgm.tv/calendar`，失败时读取同源 `/calendar` HTML。完整放送页直接解析页面七个星期的条目，手动刷新时重新读取同源页面。公开收藏使用 `/v0/users/{username}/collections?subject_type=2&limit=100&offset=…`，每页校验总数、偏移与 ID；缺页、重复 ID 或同步期间总数变化均报错，不能将部分结果当作成功的空收藏。

站内模式使用 `credentials: same-origin` 读取本站五种收藏列表 `wish/collect/do/on_hold/dropped`。验证当前登录账号、目标用户、列表容器、状态总数及相邻页链接，读取所有页后一次性替换结果。公开 API 不能自动读取私密收藏，组件不申请或保存 Token。站内/公开模式按账号记住；新用户默认使用公开 API。私密数据只留在该站点的浏览器存储中，不上传到仓库或第三方。

收藏缓存仅保存 `{id,type}`；舍弃 API 的评分、评论、标签、私密标志等字段。缓存隔离于站点 origin 和账号，公开/站内模式分别保存；公开与站内收藏 TTL 为六小时，首页放送数据 TTL 为一小时。逐页请求间隔 180ms，请求超时 20 秒；没有后台定时网络轮询。浏览器存储失败时继续内存展示。

日期按浏览器当地日期生成，日期导航固定显示选中日期所在周的周一至周日。默认选中今天，桌面三列显示昨天、今天、明天，今天单独加粗；窄屏按可用列数围绕选中日期显示。点击星期可选择该周日期，左右箭头每次只将选中日期前移或后移一天；跨周时导航仍按周一至周日排列。日期浏览只切换本地已加载的星期表和收藏交集，不发网络请求；这只是星期放送安排，不是逐集的实时上线表，不推算集数、具体时刻、停播或完结。跨午夜后未手动浏览时选中日期更新为今天。放送表可能暂时包含已完结作品，默认不会擅自排除用户“看过”的收藏。

## 挂载与视觉

- 首页挂载在 `#home_calendar` 内；数据准备好之前保留原有子节点，准备好后隐藏它们，不删除原 DOM。
- 完整页面挂载在 `.BgmCalendar` 的 `.columns` 容器内，保留原有宽度与外围标题。`/calendar?personal=off` 完全保留原始页面，不读缓存或 API。
- Shadow DOM 隔离样式。容器宽度决定列数：首页最多三列、完整页最多四列；窄屏单列。标题自动换行，不在悬浮提示里隐藏中文名称；封面保持比例，不裁掉海报。今日以粉色线和“今天”文字共同强调。
- 周一至周日日期按钮、逐日箭头和唯一的“刷新核对个人收藏”按钮均可用键盘；重绘日期保留焦点。遵循 Bangumi `data-theme`，没有显式主题时跟随操作系统。没有动效、浮层、外部字体或新增运行依赖。
- 未登录、非首页/放送页不挂载或请求数据。首次失败保留原始界面；有缓存时保留缓存与原核对时间并显示错误；失败刷新不清空已有收藏。

## 维护与验证

| 文件 | 责任 |
| --- | --- |
| `src/calendar-core.cjs` | 数据校验、ID 交集、日期和 HTML 解析 |
| `src/calendar.js` | 登录用户识别、缓存、请求、同步与局部界面 |
| `scripts/build-calendar.mjs` | 独立版本、userscript 和相同粘贴版 |
| `tests/calendar-core.test.cjs` | 五种状态、中文/图片回退、分页失败、日期边界与发布一致性 |
| `scripts/test-calendar-browser.cjs` | 隔离 Chrome 夹具；不接管用户登录浏览器 |
| `demo/calendar.html`、`demo/calendar-source.html` | 演示及发布源码入口 |

`npm run verify` 构建并验证三个组件；浏览器专项执行 `node scripts/test-calendar-browser.cjs`，无需预览服务器。演示/源码页用 `python -m http.server 8765 --bind 127.0.0.1` 打开。演示收藏是独立模拟数据，不包含用户原始记录；封面可能访问 Bangumi 图片服务。

## 调研来源与取舍

- [官方旧版放送 API 定义](https://github.com/bangumi/api/blob/master/open-api/api.yml)：提供星期、条目 ID、名称、封面，没有精确时刻或逐集更新数据。
- [官方 v0 收藏 API](https://github.com/bangumi/api/blob/master/open-api/v0.yaml)：公开分页、五种状态；私密收藏需要认证，因此完整同步使用本站登录态的收藏 HTML。
- [已有仿 B 站放送布局源码](https://greasyfork.org/zh-CN/scripts/425196-bangumi-bgm-tv-每日番剧放送-仿b站番剧时间表/code)：参考按日分列的阅读方式，没有复制其代码、全局 CSS、固定宽度或固定浮动按钮。
- 用户提供的 B 站截图确定了日期列与纵向条目形态；本项目保留 Bangumi 浅色风格、中文字体与粉色强调，不添加 B 站图标或无来源的时间/集数。
